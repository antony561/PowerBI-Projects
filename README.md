# 📊 Power BI Projects

A collection of interactive Power BI dashboards built to turn raw data into clear, actionable insights across different business domains.

---

## 📁 Projects

| Project | Description |
|---|---|
| [HR Dashboard](./HR%20Dashboard/README.md) | Workforce analytics covering headcount, attrition, diversity, and performance metrics |
| [Patient Waitlist Dashboard](./Patient%20Waitlist%20Dashboard/README.md) | Healthcare operations dashboard tracking patient waitlist volumes, wait times, and case types |
| [Sales Dashboard](./sales%20dashboard-%20random%20dataset/README.md) | End-to-end sales performance dashboard built on a sample dataset |

---

## 🛠️ Tools & Technologies

- **Power BI Desktop** — report authoring and data modelling
- **Power Query (M)** — data transformation and cleaning
- **DAX** — calculated measures and KPIs
- **Excel / CSV** — primary data sources across projects

---

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the `.pbix` file for the project you want to explore in **Power BI Desktop**.
3. Refresh the data source if prompted (update file paths in Power Query if needed).
4. Interact with the report — slicers, drill-throughs, and tooltips are enabled throughout.

> **Power BI Desktop** is free to download at [powerbi.microsoft.com](https://powerbi.microsoft.com/desktop).
